# Gerenciador de Tarefas

## Sobre o projeto

Aplicação web para organização de tarefas pessoais: o usuário cadastra tarefas com data, marca as concluídas e remove as que não precisa mais, acompanhando o total de tarefas na lista.

## Funcionalidades

- Cadastro de tarefas com descrição e data
- Validação da descrição (campo obrigatório, mínimo de 3 caracteres)
- Marcação e desmarcação de tarefas como concluídas
- Remoção de tarefas
- Contador com o total de tarefas

## Tecnologias utilizadas

- HTML
- JavaScript
- Git
- GitHub
