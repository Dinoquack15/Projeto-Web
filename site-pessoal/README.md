# Site Pessoal

## Sobre o projeto

Site pessoal estático que apresenta o autor, seus interesses e sua trajetória acadêmica, organizado em três páginas com navegação entre elas.

## Funcionalidades

- Página inicial com apresentação
- Página pessoal
- Página acadêmica com imagens dos trabalhos de cada módulo do curso
- Navegação entre as páginas por meio de botões

## Tecnologias utilizadas

- HTML
- Git
- GitHub

## Estrutura do projeto

```
site-pessoal/
├── imgs/           # Imagens usadas nas páginas
├── index.htm       # Início
├── pessoal.htm     # Página pessoal
└── academico.htm   # Página acadêmica
```

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/<seu-usuario>/projetos-programacao-web.git
   ```

2. Abra o arquivo `site-pessoal/index.htm` no navegador.

Não há dependências para instalar.
